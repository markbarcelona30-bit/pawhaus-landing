Welcome to your Remotion project!

This standalone Pawhaus video workspace was created with the blank TypeScript template, Remotion 4.0.533. The existing walkthrough is in `../docs/video/`; this scaffold is ready for future Remotion compositions.

Installation audit: npm reported 10 high-severity findings in the generated lint dependency chain, with no complete automatic fix available. This workspace is excluded from the website's Vercel deployment. Recheck with `npm audit` when updating the toolchain.

## Commands

**Install Dependencies**

```console
npm i --loglevel=error
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
